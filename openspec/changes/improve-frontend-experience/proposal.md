## Why

预约页面时段堆叠，历史预约时间与状态样式不准确，通知分组缺少空态；房间资料缺乏具体排练场景。此前前端排查还发现手机导航、认证返回目标页、方案表单和加载反馈问题。

## What Changes

- 以时长和上午、下午、晚上分组选择时段，保留所有合法选项。
- 统一北京时间展示，改善历史预约徽标、排序和资源名称；未读、已读分别显示空态。
- 新增具体演示房间、固定设备和布局示意，首页与选房页面显示真实接口资料。
- 完成当前未提交的导航、认证、会员方案与异步反馈修复。
- 不改变预约资格、清场、库存、老板例外规则，不引入 3D 框架。

## Capabilities

### New Capabilities
- `frontend-room-experience`: 紧凑时段、记录展示、通知空态及可预约的房间演示场景。

### Modified Capabilities

无业务规则变更。

## Impact

React 页面与样式、演示 seed、前端回归检查。保持现有 API 与数据库结构兼容，演示脚本不得覆盖用户修改的房间资料。
