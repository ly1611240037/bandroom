# BandRoom 功能演示脚本

建议演示时长：8–12 分钟。

1. 打开公开首页，展示场馆名称、公告、营业规则、房间和公共设备。
2. 使用顾客账号登录，展示会员卡和通知区域。
3. 选择明天的房间与时段，选择麦克风，提交一次预约。
4. 回到我的预约，展示预约时间、设备和取消按钮。
5. 取消预约，展示资源释放和次数恢复。
6. 使用老板账号登录，展示预约列表、统计卡片和筛选搜索。
7. 新增或停用会员方案，展示线下开卡表单。
8. 修改公告或营业规则，刷新公开页面验证内容更新。
9. 展示审计日志和 CSV 导出入口。
