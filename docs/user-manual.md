# BandRoom 用户手册

## 顾客操作

1. 在首页注册，填写联系人姓名、邮箱、手机号和密码。
2. 从后端日志中打开邮箱验证链接，再登录顾客账号。
3. 查看会员卡状态；会员卡由老板线下开通，支持月卡和次数卡。
4. 在预约区域选择日期、房间和半小时粒度时段，最长 3 小时。
5. 可在预约时选择额外借用的公共设备，设备 v1 不额外收费。
6. 提交后立即占用房间和设备；在预约完成前可以取消，次数卡会恢复一次使用次数。

## 老板操作

1. 使用老板账号登录后台。
2. 创建房间、公共设备和会员方案。
3. 用顾客 ID 记录线下收款并开通会员卡。
4. 设置营业时间、闭店时段、场馆介绍、公告和房间图片 URL。
5. 通过预约列表、状态筛选、搜索、统计和 CSV 导出查看运营情况。
6. 对报修、爽约和特殊预约进行处理，并查看审计日志。

## 预约规则

- 每位顾客同一时间只能保留一条未来预约。
- 预约按 30 分钟对齐，时长为 0.5 至 3 小时。
- 每次预约结束后自动预留 30 分钟清场。
- 月卡在有效期内不限次数；次数卡按成功预约扣减。
- 预约成功无需老板二次确认。
